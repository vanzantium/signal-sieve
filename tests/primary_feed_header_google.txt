PRIMARY SOURCE — Google ADK (Agent Development Kit) Python release v2.14.0

Google ADK Python version 2.14.0 release is now available. This release graduates 26 modules to stable, including 16 toolset and integration features, and adds TeamsRunner for multi-agent orchestration. A 30-node workflow's 200-turn run is 23% faster with 9% lower peak memory. Three breaking changes are listed in the release notes. The release is published on GitHub under google/adk-python.
