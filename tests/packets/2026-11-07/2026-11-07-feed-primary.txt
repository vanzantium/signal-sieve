We're introducing GPT-6 Cyber, a major leap in security research: more capable at finding and fixing vulnerabilities, and far more reliable staying within the boundaries researchers set. GPT-6 Cyber delivers major gains on key cybersecurity benchmarks over GPT-5.6 Cyber, including a 51% relative improvement on ExploitGym and a step function improvement when tested on staying within scope. It is already helping to secure real-world software, uncovering and validating thousands of exploits in security-critical codebases such as Linux and Firefox.

On ExploitGym, which tests whether models can exploit a specified vulnerability, GPT-6 Cyber scores 48.5%, up from 32.1% for GPT-5.6 Cyber. It also follows task boundaries more reliably: in a separate alignment evaluation, GPT-6 Cyber avoided exploiting out-of-scope services in 99.93% of tests without its deployment prompt, and 100% with this prompt.

These capabilities are already helping secure real systems. Our researchers used GPT-6 Cyber to develop 948 privilege escalation exploits in Linux and identify 81 previously unknown high-severity vulnerabilities in Firefox, despite extensive prior testing with frontier models. The model also helped develop candidate patches, and Mozilla has released fixes for many of the Firefox vulnerabilities. Security teams at Cisco, Calif, and CodeRabbit are using it for vulnerability research and code review.

GPT-6 Cyber is a major step up from GPT-5.6 Cyber and outperforms GPT-6 Astra on most cyber tasks, even when Astra does not refuse the request. Based on these results, we classify the model as Critical in cybersecurity under our Preparedness Framework, up from High for GPT-5.6 Cyber.

On ExploitGym, GPT-6 Cyber scores 48.5%, about 16 percentage points higher than GPT-5.6 Cyber's 32.1%. To test vulnerability discovery, we also built a new evaluation for offensive web penetration testing. Models probe web applications without access to their source code. GPT-6 Cyber achieved 40.3% recall of vulnerabilities compared with 32.0% for GPT-6 Astra.

Daybreak Red is designed to support more advanced security workflows, including developing working exploits and using them against remote targets. To evaluate these capabilities, we built a new benchmark called RemoteExploitBench, which uses known vulnerabilities in applications such as GitLab, PostgreSQL, and Jenkins deployed in a controlled environment. In our initial evaluation, GPT-6 Astra running with Daybreak Blue refused 100% of tasks, while GPT-6 Cyber completed 95%; its only failure was an exploit it could not get to work remotely.

One of these evaluations is ExploitGym Honeypot, informed by the Hugging Face incident. GPT-6 Cyber avoided exploiting out-of-scope services in 99.93% of cases, up from 94.49% for GPT-5.6 Cyber. With those prompts, GPT-6 Cyber stayed within bounds 100% of the time.

Found 81 novel Firefox vulnerabilities. GPT-6 Cyber produced evidence and reproducible tests for 81 novel vulnerabilities classified by Mozilla as high severity, and showed that an additional 30 known issues were more severe than previously reported. Mozilla began landing fixes shortly after receiving the reports.

Developing exploits for 948 Linux kernel vulnerabilities. GPT-6 Cyber reproduced 1,724 vulnerabilities and developed working exploits for 948 — more than five times the 166 exploited by GPT-5.6 Sol using the same research harness. Following the Linux community's guidance, we disclosed 304 critical findings to maintainers with candidate patches.

Our $1 billion Daybreak for Frontline Defenders grant program subsidizes access for resource-constrained teams. We're also introducing a new group within Daybreak Red (Daybreak Red for Critical Infrastructure) for approved critical infrastructure defenders.

GPT-6 Cyber is initially available through the API and Codex to a select group of approved Daybreak Red customers. We will progressively expand access to all Daybreak Red customers soon, and are also making GPT-5.6 Cyber available to all Daybreak Red customers.
